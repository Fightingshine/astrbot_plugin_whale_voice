## 0.3.1：私有曲库备份与安全恢复

- **BW-101 / Issue #4：离线维护CLI。** 原音与白名单元数据流式备份，逐文件CRC/SHA256及整体归档摘要，不包含音色引用或运行凭据。
- 只恢复到尚不存在的新目录，全部曲目默认暂停；失败目录保留隔离标记，不覆盖原库。
- 兼容Windows / Python 3.12的文件时间语义，保留变化检测与文件身份校验。
- 使用合成数据做跨平台回归；实际私有曲库的只读往返证据及发布状态见Issue #4与PR #5，不在公开仓库保存音频或备份。
- 此版本为CLI维护工具，尚未提供Web备份按钮或自动定时备份，不自动切换生产曲库。

## 后续迭代候选（待实际验证后实现）
- **BW-102 / P1：回收站与撤销误删。** 删除后可限时恢复；容量包含回收站；不为腾空间偷偷清掉原歌。
- **BW-103 / P1：重复音频检测。** 不同文件名但内容相同也能提示，不靠文件名猜测。
- **BW-104 / P2：诊断页。** 明确区分配置就绪、FFmpeg可用、真实云端合成和QQ实际收件证据；不自动付费试音。
- **BW-105 / P2：大曲库分页与排序。** 数百首时仍能快速搜索、筛选、编辑，不一次渲染全部操作按钮。
- **BW-106 / P2：逐曲授权。** 可将部分曲目限制在特定已授权群，不改变全局机器人授权。
- **BW-201 / 可选：真正歌唱服务适配。** 必须先确认服务权限、音色素材授权、费用和用户允许的测试范围；不得把普通TTS包装成已完成歌声克隆。

## 持续迭代规则

每轮选择一个可闭环需求：复现或明确验收→实现→回归→页面/运行验收→更新变更记录。GitHub登录、服务开通等外部事项保持显式待办，不伪造发布或付费调用结果。
