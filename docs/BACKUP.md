# 私有曲库备份与恢复

## 范围

`manage_library.py`是独立的离线维护命令，不需要语音服务凭据、AstrBot面板令牌或QQ连接，不会调用模型、创建音色或发送消息。

备份只包含：

- `songs/`下可用的单层音频原文件，逐文件保存字节长度与SHA256。
- 每首歌的别名、说明、原启停状态与已记录的时长。
- `BACKUP_MANIFEST.json`格式v1清单。

**不会收集**整个运行配置、`voice-aliases.json`、API Key、面板密码、群授权、使用记录或缓存。未知索引字段不打包。元数据疑似包含常见凭据/音色引用时会停止；这不是检测所有秘密的保证，音频自身及其ID3标签也可能含隐私。

备份未加密且包含原始音频，可能敏感或受使用授权限制。请保存到私有目录，不要提交仓库、附到公开Issue或上传到GitHub Release。代码采用MIT许可证不等于授予音频的分发权。

## 备份

在仓库或插件目录执行，路径替换为自己的实际目录：

```powershell
python scripts/manage_library.py backup --data-dir "<当前插件私有数据目录>" --output "<私有备份目录>/library.zip"
```

源目录需要已有`songs/`。只读模式不会自动创建原库目录、`.song-staging/`或索引，不改变歌曲和设置。输出必须在源数据目录之外，且不存在；即使同名旧ZIP损坏也不覆盖。

工具以64KB分块复制原音，文件不重新编码。音频使用ZIP存储方式，避免对已经压缩的歌曲重复消耗CPU。完整校验和归档摘要会增加磁盘读取，但不会把整首歌或整个ZIP载入内存。临时归档先完整校验并落盘，再独占发布。请预留与原音总量相当的磁盘空间。

备份过程中歌曲、文件列表或索引变化时停止发布，请在曲库空闲时重试，不会自动暂停机器人或删除文件。不能用本工具代替异地备份、磁盘健康监控或断电保护。

## 校验

```powershell
python scripts/manage_library.py verify --archive "<私有备份目录>/library.zip"
```

检查清单格式、条目和元数据、路径安全、CRC、大小与SHA256；备份和校验结果也返回整个ZIP的`archive_sha256`，可与自己另外保存的备份记录比对。不执行ZIP里的内容、不使用`extractall`，也不解析为音频或调用FFmpeg。**校验通过是文件完整性证据，不证明来源可信、音频能正常解码或具备使用授权。**

当前格式只接受普通文件、ZIP_STORED/ZIP_DEFLATED，不接受加密、分卷、ZIP64、链接、特殊设备、重复JSON字段、未知条目、归档注释或中央目录附加字段。先检查ZIP尾部与中央目录大小，再创建ZIP解析对象，限制异常目录造成的内存占用。

沿用当前曲库边界：最多500首，每首50MB，总音频1GB，清单2MB。文件名必须能安全跨平台恢复，大小写或Unicode等价重名、Windows设备保留名和路径字符会被拒绝，不偷偷改名。

## 恢复

```powershell
python scripts/manage_library.py restore --archive "<私有备份目录>/library.zip" --destination "<尚不存在的新数据目录>"
```

1. 先验证完整归档，校验失败时不创建目标目录。
2. 独占创建新目录；目标已存在或被并发操作先创建时，不覆盖、不清空。
3. 先写入所有曲目暂停的索引，再恢复原音并逐文件复核SHA256。
4. 完成后移除`.restore-incomplete`。所有曲目仍暂停，需要管理员检查后手动启用。

不恢复全局平台或群授权，不自动替换当前机器人数据目录，不复制云端音色引用。恢复结果只能作为新库检查；如需切换生产目录，先停下有关写操作并保留原库，不要直接覆盖。

## 恢复失败

中途磁盘或I/O失败时，新目录可能保留部分文件、暂停索引和隔离标记。工具不递归删除任何用户目录；不要将未完成目录投入运行。0.3.1会拒绝打开带隔离标记的库，旧版本也会看到暂停的索引。

排查磁盘空间和权限后，使用另一个新目录重新恢复。不要手动删除隔离标记来假装恢复完成，不支持强制覆盖或自动断点续写。

## 只读源与私有配置

曲库索引损坏、源目录链接或恢复未完成时会停止操作，不自动清零。现有专属音色文件与群授权始终留在原运行环境；需要迁移音色时单独按`MIGRATION.md`处理，不把它混进曲库备份或公开代码。
